# AmyVasc

Analysis and figure-reproduction code for the AmyVasc manuscript.

> **Large-Vessel Venous Signal Confounds Apparent Amygdala Activation in
> BOLD fMRI.** Zachary Diamandis, J. Michael Tyszka, and Ralph Adolphs.

This repository provides the analysis and figure-reproduction workflow used to
evaluate peri-amygdalar venous signal in HCP-YA and Dense Amygdala fMRI data.

## Workflow

Python 3.12 and [uv](https://docs.astral.sh/uv/) are required.

```bash
uv sync --locked --python 3.12
```

Obtain the imaging and atlas inputs listed below, then run the analysis stages
in `analysis/README.md`. After stages 1--9 are complete, export the 26
manuscript-facing tables with:

```bash
uv run python analysis/10_export_figure_tables.py \
  --roi-dir <roi-summary-dir> \
  --pstc-dir <pstc-summary-dir> \
  --spatial-dir <spatial-summary-dir> \
  --smoothing-dir <smoothing-summary-dir> \
  --rapidtide-dir <rapidtide-summary-dir> \
  --figure7-source-profiles-dir <figure7-profile-dir> \
  --s5-source-profiles-dir <s5-profile-dir> \
  --s4-source-profiles-dir <s4-profile-dir> \
  --s4-positive-controls-dir <s4-control-dir> \
  --atlas-overlap <atlas-overlap.tsv> \
  --output-dir outputs/source_data/tables
uv run python reproduce.py all
```

The generated tables are written to `outputs/source_data/tables/`; figure files
are written to `outputs/`. Selected panels can instead be rendered by passing
figure IDs, for example `uv run python reproduce.py 1 4 7 8 S5`. Available
identifiers are 1, 4, 5, 6, 7, 8, S4, S5, and S7.

Image panels are rendered separately from prepared NIfTI maps with
`analysis/11_render_vascular_panels.py` and `analysis/12_render_hcp_maps.py`.
See `figures/README.md` for inputs and examples. The vascular panels require
the follow-up data available from the authors on request.

## Analysis workflow

The scripts in `analysis/` implement cohort selection, task GLMs,
within-participant fixed effects, mask and atlas preparation, ROI and spatial
summaries, smoothing analyses, resting-state lag analysis, and task-profile
source attribution, together with the atlas-overlap analysis. See
`analysis/README.md` for inputs and execution order.

The workflow begins with preprocessed HCP-YA and Dense Amygdala imaging data.
The follow-up Emotion, TOF, and QSM acquisitions and their prepared vascular
derivatives are available from the authors on request, as stated in the paper.

## Repository contents

- `amyvasc_release/`: reusable analysis functions.
- `analysis/`: command-line analysis scripts.
- `source_data/`: manifest of the tables generated by the analysis workflow.
- `figures/`: renderers for the generated source-data tables.
- `subject_pools/`: HCP-YA cohort selection criteria.
- `reproduce.py`: entry point for rendering quantitative panels.

## Data access

HCP-YA participant-level data, Dense Amygdala imaging data, and atlas source
files are not redistributed here. Users must obtain them from their original
distributors and comply with the applicable data-use and acknowledgment terms.
No HCP data or HCP-derived analysis tables are included.

### Human Connectome Project data

The HCP-YA inputs required for the HCP-dependent analyses are not distributed
in this repository. Users must obtain them through the
[Human Connectome Project](https://www.humanconnectome.org/study/hcp-young-adult)
after registering and accepting the
[WU-Minn HCP Consortium Open Access Data Use Terms](https://www.humanconnectome.org/study/hcp-young-adult/document/wu-minn-hcp-consortium-open-access-data-use-terms).

The MIT License applies only to the code in this repository and does not grant
rights to upstream HCP data or locally generated HCP-derived data.

Data were provided in part by the Human Connectome Project, WU-Minn
Consortium (Principal Investigators: David Van Essen and Kamil Ugurbil;
1U54MH091657), funded by the 16 NIH Institutes and Centers that support the NIH
Blueprint for Neuroscience Research, and by the McDonnell Center for Systems
Neuroscience at Washington University.

Figure 2A contains third-party anatomical artwork and is not distributed in
this repository.

## Data and atlas sources

- HCP-YA: 2025 Task3T Recommended derivatives for task analyses and S1200
  minimally preprocessed data for resting-state analyses
  ([data releases](https://www.humanconnectome.org/study/hcp-young-adult)).
- Dense Amygdala: OpenNeuro
  [ds006947 v1.0.1](https://doi.org/10.18112/openneuro.ds006947.v1.0.1).
  This public release supplies the original movie/structural data; it does not
  include the follow-up Emotion or vascular acquisitions.
- CIT168: probabilistic
  [amygdala](https://doi.org/10.17605/OSF.IO/R2HVK) and
  [subcortical](https://doi.org/10.17605/OSF.IO/JKZWP) atlases.
- HCP-MMP1: the Glasser et al. cortical parcellation and the
  [v8 registration-fusion volumetric atlas](https://doi.org/10.6084/m9.figshare.24431146.v8).
- Gray-matter support: FSL FAST applied to
  `MNI152_T1_2mm_brain.nii.gz`, combined with TemplateFlow's
  `tpl-MNI152NLin6Asym_res-02_atlas-HCP_dseg.nii.gz`. These upstream images
  are not redistributed here.
- Tian S2: the 3T Scale II
  [Melbourne Subcortex Atlas](https://github.com/yetianmed/subcortex/tree/master/Group-Parcellation/3T/Subcortex-Only).
- Harvard-Oxford: the subcortical structural atlas distributed with
  [FSL](https://fsl.fmrib.ox.ac.uk/fsl/docs/other/datasets.html#harvard-oxford-cortical-and-subcortical-structural-atlases).
- VENAT: the [venous neuroanatomy atlas](https://pubmed.ncbi.nlm.nih.gov/31278570/),
  registered from MNI152NLin2009cAsym to MNI152NLin6Asym for Figure 3.

Small checks of the scientific calculations and file interfaces use synthetic
inputs only: `uv run python -m unittest discover -s tests`.
